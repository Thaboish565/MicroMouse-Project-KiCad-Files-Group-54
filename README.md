# MicroMouse Project KiCad Files Group 54
 Contains the KiCad files for EE3088F 2025 Project PCB Files Group 54 RDJTHA001 JMSROJ001

This repository contains the design, implementation, and documentation for the EEE3088F 2025 Micro-mouse project at the University of Cape Town. 
The project focuses on the power subsystem of an autonomous maze-solving robot, controlling two main motors and two auxiliary motors  with a  LiPo battery, monitored by an INA219 sensor. 
Key components include a DRV8833 H-bridge and STM32 microcontroller. 
The repository includes schematics, PCB designs, firmware, and the final report with test results and recommendations
